## 评分规则

1. 只使用“开始前阵容”作为输入；不从战斗中途反推初始状态。
2. 同行、同格的多个僵尸保留为独立单位；不能按格去重。
3. 含无法确认或模拟器不支持的特殊物件的轮次不计入正确率。
4. 结果不确定时保留 `unknown`，不强行判定。
