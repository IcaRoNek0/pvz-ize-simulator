# 本地布阵器

```bash
python3 -m pvz_ize editor
# 自定义端口
python3 -m pvz_ize editor --port 8766
```

访问终端显示的本地地址。服务只绑定 127.0.0.1，不上传阵型、不依赖外部字体或 CDN。Ctrl+C 停止。

支持全部 38 种植物和 28 种非僵王僵尸。选择植物/僵尸和单位后点击五行九列棋盘放置；同格可放多个僵尸，植物支持主植物、底座、南瓜层。选择已放单位编辑属性或删除。原九格阵型码默认导入第三行；完整 JSON 可表达多行、像素位置、血量/防具、计时器、魅惑、矿工状态、大蒜方向及动画初态等。

普通九格代码只包含单位和位置，不能无损保存属性。完整属性请导出 JSON；规范化后会固定已抽样冷却、移速参数等，保证相同模型与种子下重放一致。重新随机试验应删除希望重抽的字段。位置 x 与 col 二选一；僵尸 col 支持小数，蹦极必须整数。

礼盒的 `jack_countdown_frames` 是开盒前倒计时。设置 300 表示第 300 个未定身更新开始开盒，再等 110 帧爆炸；0 为首帧开盒。它不是绝对爆炸时刻，未填写则沿用模型的随机初始计时。示例：`examples/jack-timer.json`。

跳跳从 0.5.2 起使用弹跳周期：持杆默认直接速度 0.45 px/帧，显式 `speed` 可覆盖它，动画模式的 `velocity_parameter` 可直接设置原版位移参数。断杆会重设原版步行速度参数 0.45，并切换步行轨道。寒冷减速不延长弹跳周期。

属性留空表示省略并使用模型默认值，0 是明确输入；植物 state_timer 的 0 在部分瞬发植物中代表默认准备时间。此编辑器编辑的是初始状态，不支持任意中途运行快照恢复。

预测结果为近似模型结果。max_frames 是计算预算，耗尽返回未决，不表示植物获胜。Who 规则只统计第三行威胁；需要多行全场结算时选择 IZE。僵王不在本轮界面范围；旧 CLI 的实验性僵王功能保留但不作为本轮验收项。
