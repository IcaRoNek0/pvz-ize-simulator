# 模型约定与精度边界

第一轮历史模型 ID：`ize-mean-speed-v2`。第二轮当前模型为 `ize-expanded-v3`，新版规则与纠错以 `FIDELITY_V2.md` 和 `INPUT_V2.md` 为准；本文件保留早期研究过程。本文件描述**实际实现**，源码研究见 `research/plants.md`、`research/zombies.md`。研究文件中提到的原版机制不代表均已完整实现。

## 1. 状态与帧顺序

- 公共 row/col 均一基。植物左上角 `x=40+80*(col-1)`；IZE 僵尸左上角 `x=10+80*(col-1)`。
- t=0 加载全部实体，先剔除初始 HP=0、已经进家/出界实体，再检查结算。所有其余僵尸第一帧就参与移动，不设出生等待。
- 每逻辑帧 10 ms；按输入顺序更新植物，再僵尸，再弹丸，然后清理弹丸及检查胜负。新发弹丸当帧更新；伤害顺序执行，不做同时伤害聚合。
- 按输入脑子集合判定，不复用原版固定五脑计分；先判全脑消失，再判无在场僵尸。
- 每只僵尸状态为 `active`、`dead`、`entered_house` 或 `exited`。`active` 中包括掉头但本体尚有血的僵尸。
- 普通/小鬼/路障/桶/门的进家阈值 x<=-100，橄榄 x<=-175；无头在对应阈值+70 处清除。**本版将输入 x>850 的僵尸当作已右侧退场**，不会把它当成将来入场的刷新单位。矿工出土后可向右移动，详见第7节。
- 全部脑子消失后立即结算，不要求僵尸离场；无头仍在场则继续等其掉血死亡/离场。HP<=0 立即清除，不保留死亡动画或战利品。

## 2. 僵尸

|类型|本体|头盔|手持盾|默认实际均速 px/帧|
|---|---:|---:|---:|---:|
|普通|270|0|0|0.143|
|路障|270|370|0|0.143|
|铁桶|270|1100|0|0.143|
|铁门|270|0|1100|0.143|
|橄榄|270|1400|0|0.32|
|IZE 小鬼|70|0|0|0.423|

血量来自参考源码；**均速是近似选值**。原版常见 0.23..0.37、0.66..0.68、0.9 是动画驱动速度参数，不等于每帧真实位移，不能直接照搬。初版无速度随机重抽、步态与动画相位；显式 `speed` 可做受控实验。

- 默认受击框 `[int(x)+36,int(x)+78]`，橄榄为 `[int(x)+50,int(x)+107]`；嘴框 `[int(x)+50,int(x)+70]`。
- 植物普通可啃食框 `[plant.x+10,plant.x+70]`，高坚果到 `plant.x+90`。同排横向交叠>=20 才可啃，选输入顺序首个可啃目标。地刺不被啃。
- 先按上帧吃状态决定是否移动，再每4帧（`age % 4 == 0`）检查植物/脑子并啃食。年龄先递增；目标没了，也需等下一次检查解除吃状态。
- 植物一口4 HP，脑子一口1，脑子初始70；多僵尸共享脑 HP。嘴框左界<=20 才可吃脑。
- 长时间未受击的僵尸啃坚果/高坚果加倍。实现按 `age-last_damage_age>500` 检查；受击更新到 `age+25`。纯盾受击原版只把本体命中计数抬到至少0，本工具也抬至25，存在至多25帧细节差异。初始计数从0开始，不支持导入历史受击计数。
- 普通伤害按手持盾->头盔->本体溢出；地刺、反向豌豆绕手持盾，但不绕头盔；大喷、土豆、窝瓜和火球同时伤盾和本体/头盔。
- 本体严格低于初始上限整除3后掉头，不能再咬；每帧有1/5概率自损（初始本体>=500时为3，否则1），直到死亡。掉头仍能走且仍可受击。
- 冰豆实际打到头盔/本体时施加1000帧寒冷，纯盾挡住时不施加。移动均速乘0.5，啃食周期变8帧；在僵尸更新开头递减寒冷计数。火球主目标清寒冷。

## 3. 植物

- 通用 HP300、坚果4000、高坚果8000。所有菇类视为清醒，IZE土豆已出土。
- 普通射手周期136..150帧；无目标时周期仍倒数并重抽。初始攻击 CD 按平稳剩余周期分布采样，参考 rpze，而非游戏刚创建植物的均匀0..150分布；可通过 `cooldown` 精确指定。
- 初始化采样与运行时使用独立的种子随机流，保证 `--dump-initial` 后重放不因省去初态抽样而改变后续 RNG。只保证本工具同版本可复现，不保证原版同 seed 同结果。
- 实际前摇：豌豆/寒冰/三线34，双发/裂荚25，小喷28，大喷49，胆小24。双发在CD=25与0分别准备一发；裂荚左侧两发、右侧一发。裂荚右前摇采用移植源码25，而非rpze注释34。
- 射手准备时索敌；出手时不依赖原目标存活。大喷实际出手时重新对范围内所有目标结算。
- 大喷同排攻击区 `[x+60,x+400]`，严格交叠>0，盾与本体/头盔各20伤群攻；小喷索敌区 `[x+60,x+290]`。

|特殊植物|本版实际行为与简化|
|---|---|
|三线|向有效的三行各发一颗。**直接按三排水平弹道**，未模拟侧排弹丸纵向收敛，近距离/跨排碰撞可能不同。|
|胆小|用半径120与自身/邻排矩形检查恐惧；无待发射击时抑制攻击并将CD置149。**省略缩头/起身动画迟滞**。|
|地刺|触发后第25帧对同排 `[x+20,x+50]` 严格交叠目标伤20，状态CD100，持续触发相邻伤害间隔101。忽略通用射击CD。|
|土豆|已armed，带头目标触发（正在啃食时外扩30），当帧同排半径60伤1800并消失，不要求等成熟。|
|磁力菇|上下最多两行，半径270/啃食320，近似按二维矩形距离；优先距离含80*行差惩罚；当帧吸除桶/橄榄头盔或门盾，1500帧CD，不吸路障。也可吸持梯、已放梯和矿工镐，详见第7节。|
|大嘴|索敌后70帧重新索敌，无视护甲吞一只；成功后固定4000帧消化。**省略额外咬合/吞咽动画**，原版完整恢复可能更长。|
|窝瓜|观察80、预跳45、空中55，共180帧后范围伤1800；第125帧估计落点，按30帧均速预测；**不完整复刻原版重新选敌/落点矩形与100帧残留动画**，落地立即移除。|
|火炬|植物阶段对弹丸区交叠>=10转换；冰豆只解冰为普豆，同一树不能再变火球，另一树可继续转换。火球40主伤、通常13旁伤，旁伤多目标时按参考公式缩放，盾/体同时受伤。未复刻夹树跳过碰撞特判。|
|向日葵/保护伞|可啃食阻挡物；向日葵不产阳光，保护伞防蹦极；无投篮系统。|

`state_timer` 只在土豆/磁铁/大嘴/窝瓜初始等待时生效。没有完整植物 state/动画/待发弹丸的中间态输入；地刺的攻击状态和普通射手前摇也不能用此字段恢复。

## 4. 弹丸

- 直射速度3.33px/帧，反向取负；20伤。小喷弹丸年龄>=75时先消失；其他弹丸横坐标<-80或>900移除。
- 默认豌豆/冰豆/火球横框 `[int(x)-15,int(x)+40]`，蘑菇 `[int(x),int(x)+40]`；同排接触>=0即碰撞，命中最靠左的一个目标。
- 普通豌豆炮口固定植物x+60、反向x+10；三线x+45、小喷x+40、胆小x+29。普通炮口固定值为**离线近似**，原版由动画头部偏移决定，小喷出生坐标扰动也未实现。
- 本工具**使用移动后的整数弹丸坐标**判断碰撞；参考移植中部分路径使用上一帧整数缓存，可能差1帧。没有逐帧像素精度保证。
- 火球旁伤同排，横区间以本弹丸框左界为起点宽100，排除主目标后通常每只13；若 `13*n>40` 则 `max(1,1600//(39*n))`。只有主目标去寒冷。
- 最终 `projectiles` 是残留在飞弹丸；结算不必等待它们退场。

## 5. 验证证据分层

1. **静态事实**：研究笔记引用当前参考源码及rpze注释；原版游戏只记录本地文件哈希和PE架构，不宣称目录标签已完成版本鉴定。
2. **自动化验证**：单元测试覆盖本工具实现约定，端到端测试验证CLI、产物和同初态重放；不是原版等价性验证。
3. **样例结果**：`outputs/examples/` 是本模型实际执行结果，不是游戏实测数据。
4. **尚未执行**：启动原版或移植版、原版录帧差分、实测胜率和精度指标；动画数值提取已完成，见第7节。

## 6. 下一阶段建议

先用Windows上的rpze采集并保存明确的输入/实际初态/期望结果，再考虑抽离移植版的无渲染逻辑或提取动画数据。首批差分用例：

- 空路普通/橄榄/小鬼的每帧位移与到脑时间；不同步态、恢复走路后的速度重抽。
- 脑子首末70口、多人共享、寒冷周期，碰到植物时停止位置。
- 普通本体90/89血临界；门盾吃冰、穿盾攻击、火球主伤和溅射。
- 双发首尾发射、小喷炮口扰动与75帧寿命、三线近距离侧排弹道。
- 胆小缩起迟滞、大嘴完整恢复、窝瓜转向/落点、撑杆跳高坚果。

在这些数据到位前，不给出“与原版一致”“100%准确”的结论，也不把尚不支持的单位静默纳入计算。

## 7. v2 扩展与勘误（优先于前文旧版范围说明）

已支持 rpze 标准 IZE 表中的全部19种植物与9种僵尸；加上扩展单位共20植物、12僵尸类型。完整别名覆盖由 `tests/test_ize_coverage.py` 直接读取参考表AST验证，不导入Windows依赖。标准 IZE 以外的气球/巨人等仍拒绝。

### 地面特殊单位

- 撑杆本体500，初始均速0.32，一次跳跃后0.143；到脑前自动收杆，可吃脑。高坚果阻挡。进家界-150。跳跃180cs来自原版资产43动画帧/24fps向上取整，落点/撞高坚果时序仍简化。
- 梯子本体500、盾500，携梯均速0.38，失梯后0.143。遇坚果/高坚果放梯50cs（12动画帧/24fps），跨越不咬坚果。已放梯记录在结果 `ladders` 中，其他地面单位也能跨越；磁铁可吸持梯或已放梯。爬梯暂用120cs且简化高度/水平曲线。
- 矿工本体270、帽100，地下实际均速0.67，只受地下类攻击/磁铁，不吃脑。左端出土130cs、晕眩350cs后朝右均速0.11，不能吃脑，右出界不阻塞结算。地下失镐先等200、出土130再向左步行；失镐不消除帽血。反向受击/嘴框按120px精灵镜像。
- 详细阶段、来源和例外见 `research/ground-special.md`。

### 舞王、伴舞与蹦极

- 舞王本体500，初段300..311cs以0.5向左月球步，碰植物可提前召唤。指向42cs后召四伴舞（越界行不召），伴舞出土150cs；停顿200cs后按460cs周期步行/舞步，步行均速0.22。缺员补召，领舞死亡后伴舞独立行动并计入结算。舞王/伴舞进家界-130。
- 蹦极本体450，落点为植物格坐标，不减30；按原始高度3000..3150、每帧下降8估计下降时长，落地等300、抓取63、升空75后退出。高空阶段不受地面攻击，落地可受击；保护伞覆盖自身及相邻行列一格，防止偷取。抓取阶段目标植物暂停攻击，升空时移除；不模拟阳光和多层种植。
- social模块仅负责阶段，不另行结算；伴舞是真正新增实体，新生成实体从下一帧更新，初始输入所有实体仍从第0帧存在。初始化阶段事件可能在frame0出现。
- 详细舞步与动画限制见 `research/social-special.md`；固定全局舞步相位、部分寒冷动画时长和下降提前触伞等仍近似。

### 杨桃与玉米

- 杨桃周期136..150、前摇39，后方/异排按预测角度窗索敌，被啃时可触发。五颗星从(x+25,y+25)向左、上下、右上/右下30度飞行；没有向右水平星。速度3.33，更新纵坐标和所在行；左星绕门盾，其他方向不绕；年龄<25且横速度>=0的星对矿工有碰撞豁免。
- 玉米周期286..300、前摇29，攻击准备时1/4概率黄油。发射时重新选目标并按50cs均速预测落点；抛物线横速range/120、初始垂直速度rangeY/120-7、重力0.115。不是瞬间或全程追踪。普通20、黄油40，绕门盾但不绕头盔；落地错过目标明确消失。
- 黄油400cs，期间暂停移动、啃食与特殊动作，计数到0恢复；无头/打到脱头时不附加黄油，掉头清除已有黄油。

### 伤害勘误

对照 `ConstEnums.h:250`、`Plant::Fire` 与 `Zombie::TakeDamage` 后，v1研究中“大喷穿盾”不能解释为“门盾完全不受伤”：大喷标志2是 **同时伤盾和本体**。v2每次门盾和本体各20；土豆/窝瓜1800同样同时伤盾/本体。地刺与反向豌豆才是绕盾不伤盾。相应回归已更正。旧版输出保存在 `outputs/examples-v1/`，不混充v2结果。

### 资产证据与仍未验证事项

`scripts/inspect_reanimations.py` 已从本地PAK只读提取15个动画资源并校验schema、解压大小、完整字节消费；结果 `outputs/reanimation-inspection.json` 保存动画帧数、ground数值及哈希。解析格式见 `research/reanimation-format.md`。已用其参数替换跳跃/放梯/矿工晕眩、舞王指向、蹦极抓取的猜测时长。完整动画驱动位移、原版RNG消耗、复杂碰撞和原版运行差分**仍未完成**；现有mean-speed模型告警继续保留。启动/运行差分尚未执行。
